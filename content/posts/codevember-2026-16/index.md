Today is day 16 of the Codevember challenge. Codevember is a coding challenge where people build small projects based on a word or theme for each day in November. I am following [@thespite](https://x.com/thespite) (Jaume Sanchez Elias) on X. He generated an unofficial prompt list for every day. [Jaume’s post](https://x.com/thespite/status/2116974998212772095?a=Ja7aa-sznyd9T6J_JNo&s=46) Today’s day 16 prompt is:

{{< keyword >}}spore{{< /keyword >}}

This is the prompt I started with and gave to the GitHub Copilot app:

> [!NOTE]
> Theme for the day: {{< keyword >}}spore{{< /keyword >}}
>
> Create a spore image (about 5 spores) with a bigger view of one of the spores in the middle - when the big spore is clicked on show/anamate all the steps it takes to become a new form of life - like a plant or mushroom. Use three.js and site should be interactive and responsive.

Copilot was able to create a simple one-page website demonstrating the lifecycle of a spore growing into a mushroom. Three.js was used, and the page is interactive and responsive. I started out using the GitHub Copilot Windows app, but it had a hard time understanding that I wanted to create a separate working repo for another idea I had about spores. It wanted to continue in the first repo and then asked me to open an existing repo. I ended up switching to VS Code to finish.

Check out the build here: [Codevember Day 16 ~ spore](https://gregpuzzles1.github.io/codevember-2026/16/)
