I decided to take part in the Codevember challenge. Codevember is a coding challenge where people build small projects based on a word or theme for each day in November. I am following [@thespite](https://x.com/thespite) (Jaume Sanchez Elias) on X. He generated an unofficial prompt list for every day. [Jaume’s post](https://x.com/thespite/status/2116974998212772095?a=Ja7aa-sznyd9T6J_JNo&s=46) Today’s day 12 prompt is:

{{< keyword >}}feather{{< /keyword >}}

This is the prompt I started with and gave to Copilot in VS Code:

{{< alert icon="code" >}}
The theme for this web app is:

{{< keyword >}}feather{{< /keyword >}}

Please review the attached video (space racer game) and its included GitHub url for guidance as an example. Create something similar to this using three.js Create an exhibition of the birds of northern Colorado. The northern Colorado landscape is mountainous along with plains. Some birds can be flying, some can be on the ground eating, others can be singing in a tree. Please use the best AI model for representing the actual size ratios and markings/features of the birds listed below. Keep in mind the theme is feather. List of birds in Northern Colorado: house sparrow, robin, common grackle, starling, bluejay, swallow, red-winged blackbird, blackbird, yellow-headed blackbird, Cooper’s hawk, red-tailed hawk, bald eagle, great-horned owl, hummingbird, house finch, killdeer, pigeon, duck, geese, white pelican, great cormorant, seagull, magpie, pheasant, lark bunting, dove.
{{< /alert >}}

I was able to create a simple one page site with some of the birds in Northern Colorado. It did not take too long. I think tomorrow I will try working directly with three.js and see what I can come up with. Today, I have 3D rotating birds but they are not built with three.js.

Check out the build here: [Codevember Day 12 - feather](https://gregpuzzles1.github.io/codevember-2026/12/)
